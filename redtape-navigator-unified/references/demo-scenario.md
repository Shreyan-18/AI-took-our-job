# Demo Scenario (3-Minute Hackathon Pitch)

1. User enters: *"I want to open a small bakery in Kolkata."*
2. Live 3-tier Research hits FSSAI (Central), West Bengal Labour/Fire (State), and KMC (Municipal) with clickable `.gov.in` links.
3. Compliance Matrix renders: FSSAI + KMC Trade Licence `Required`; Fire NOC `Conditional` on seating/LPG.
4. One concise Interview turn asks 3 questions (seating, gas vs electric, rented vs owned + turnover).
5. User replies in one sentence → Compliance re-evaluates live; Audit Trail logs Fire NOC downgraded to `Not Applicable` with exact reason.
6. Document & Portal Agent generates both a filled PDF preview (with `[PENDING_USER_INPUT]` stamped on PAN) AND a FoSCoS Digital Web Portal copy sheet + Playwright draft manifest.
7. Validation Gate passes with masked PII; Human Review Dashboard displays readiness, attachments, and stops before submission.
